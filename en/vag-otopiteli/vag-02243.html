VCDS 02243 Control Head for Aux. Heater - open circuit, T6

Code 02243 "Control Head for Aux. Heater (E407)", cause 011 open circuit (sometimes marked intermittent). The description comes only from t6forum threads (T6); no official Ross-Tech or manufacturer description was found, so the wording is cautious.

Can you drive

You can drive, the heater may not work

You can drive: it concerns the link between the heater and its control panel (roof display E407), not vehicle control.

What the code means

CodeName
02243Control head for aux. heater (E407)

Address 18 in VCDS is called Aux. Heat (auxiliary heater).

Possible causes

  • t6forum thread (T6 with an air heater): the roof display was not compatible with the air heater; fitting a compatible version 7E5919037D, F or H and coding the display (address 6E) to 0002106 helped.
  • Another t6forum thread: code 02243 with the cause "open circuit, intermittent" stored in address 0B (Sec. Air Heating) after the heater was disconnected from its control unit.

What to check, in order

  1. Check the connectors and wires between the roof panel and the heater.
  2. Check that the roof display suits your heater type (water or air): compatible part numbers are in the forum thread.
  3. Check the coding of the display (address 6E) and of the heater unit; the last digits depend on whether a remote control is fitted.
  4. Clear the code and see whether it returns.

When a workshop is needed

The code stays after the wire check: workshop, for the display, coding and heater unit firmware. Do not code or flash without understanding the consequences.

Questions and answers

What does VCDS 02243 mean?

An open circuit between the heater and its control panel. The description is confirmed only by T6 forums.

Why are the two sources weak?

Both are t6forum threads: owners practical experience, not a factory document. We note it on the page.
