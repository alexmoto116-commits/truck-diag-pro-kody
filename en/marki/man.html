The reference covers 107 codes from the factory tables of MAN — the full list by system is below, stop-now codes first.

MAN codes: what to know

MAN uses two formats. In the free tables the code follows J1939 (SPN and FMI): 107 codes, where the brakes, transmission and exhaust stand out most. The dealer codes are different: five-digit numbers such as 00001, where the module comes first and then the fault; there are 1807 codes of them. First work out which unit logged the code, and only then read the explanation.

How to read a code

A code has two halves. SPN is what is actually at fault — the sensor, component, or parameter. FMI is what is wrong with it — value out of range, open circuit, short circuit, invalid data. So “SPN 100” alone is not a diagnosis yet, but “100/1” already tells you oil pressure has dropped below normal.

If there are several codes at once

That is almost always how it goes: one fault drags five or six codes behind it. An empty AdBlue tank first throws a level error, then interrupted dosing, then a NOx excess and a torque derate.
