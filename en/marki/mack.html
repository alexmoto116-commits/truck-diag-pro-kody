Mack fault codes

The reference covers 641 codes from the factory tables of Mack, grouped by control module (MID).

Mack codes: what to know

A Mack code has three parts: the MID module number (for example 128 is the engine, 142 is the chassis and dash), the PID/SID parameter, and the FMI fault type. There are 641 codes by module, and on this page they are grouped by module. There is also a separate dealer table in OBD-II form, such as P0016, which is not linked to the MID or FMI.

How to read a code

A code has three parts: MID is which control unit reported it, PID/SID is which parameter or component is at fault, FMI is the type of fault (short circuit, open circuit, value out of range). On the scanner the code usually shows as MID-PID/SID-FMI, e.g. MID128 PID100 FMI4.

Know the code number? Type it into the search — or paste the whole list from the scanner and we will show which fault is the real one.
