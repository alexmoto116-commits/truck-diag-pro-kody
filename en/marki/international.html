International fault codes

The reference covers 587 codes from the factory tables of International — the full list by system is below, stop-now codes first.

International codes: what to know

International has the largest free SPN table on the site: 587 codes. Most codes have no standard name, so the component name on the page comes from the factory entry. Among the codes where the component is known, the most common are transmission, brakes and the power supply. International also has its own dealer format: 118 codes.

How to read a code

A code has two halves. SPN is what is actually at fault — the sensor, component, or parameter. FMI is what is wrong with it — value out of range, open circuit, short circuit, invalid data. So “SPN 100” alone is not a diagnosis yet, but “100/1” already tells you oil pressure has dropped below normal.

If there are several codes at once

That is almost always how it goes: one fault drags five or six codes behind it. An empty AdBlue tank first throws a level error, then interrupted dosing, then a NOx excess and a torque derate. Fix the root cause and the rest clear on their own. Paste the whole list — we will show which code is the root cause.
