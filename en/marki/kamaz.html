KAMAZ fault codes

The reference covers 534 codes from the factory tables of KAMAZ — the full list by system is below, stop-now codes first.

KAMAZ codes: what to know

KAMAZ codes follow the J1939 standard: a component number (SPN) and a fault type (FMI). The free tables on the site cover 534 codes. Where the component is named, the most common ones are the exhaust and AdBlue system, fuel and intake. A code only makes sense as a pair: an SPN without its FMI tells you which component, not what happened to it. With FMI 3, 4, 5 or 6 the problem is usually the sensor circuit, so check the connector and the harness first. If the code you need is not in the list, type the full code into the search on the homepage.

Start with these codes:

  • SPN 190Engine speed
  • SPN 596Cruise Control Enable Switch
  • SPN 597Brake Switch
  • SPN 598Clutch Switch
  • SPN 630Calibration Memory

How to look a code up

KAMAZ-5490 (Mercedes, K-line): the scan tool shows the K-line code as "ADM3 10514" or "MR2 12020". In the table these numbers sit on the SPN 100 FMI 14 row (KAMAZ-5490 block below).

Cummins ISB 6.7: a code like "FC 111" corresponds to SPN 629 FMI 12.

KAMAZ Euro-3 (Bosch MS 6.1): "blink 21" is the number of lamp flashes; 21 is the high-pressure fuel pump. The full list of blink codes is in the table below.

ZF AS-Tronic gearbox

ZF numbers its faults its own way, not by the J1939 SPN standard, so the gearbox has its own page: ZF AS-Tronic fault codes.

How to read a code

A code has two halves. SPN is what is actually at fault — the sensor, component, or parameter. FMI is what is wrong with it — value out of range, open circuit, short circuit, invalid data. So “SPN 100” alone is not a diagnosis yet, but “100/1” already tells you oil pressure has dropped below normal.

If there are several codes at once

That is almost always how it goes: one fault drags five or six codes behind it. An empty AdBlue tank first throws a level error, then interrupted dosing, then a NOx excess and a torque derate. Fix the root cause and the rest clear on their own. Paste the whole list — we will show which code is the root cause.
