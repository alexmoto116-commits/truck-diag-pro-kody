Planar fault codes

The database covers 21 dealer codes — Planar uses its own factory format, outside the J1939 SPN/FMI standard. A few examples below; look up your own code in the search on the homepage, where you can also pick “Planar” from the brand list.

Planar codes: what to know

Planar is a heater: 21 codes, with codes such as 1, 10 and 11. A number comes from one of two systems: a repair-table code or the blink count of the PU-5 remote, so each entry says which. The most common areas are overheating, the blower, the fuel pump, the glow plug and the remote link. Code 1 concerns the heat exchanger of the heater, so the fault is in the heat exchanger, not the engine.

Planar code examples

1Heat exchanger overheating: the overheat sensor tripped (above 250 C) and the heater shut down
2Possible overheating: control unit sensor temperature above 55 C (insufficient cooling during 5-min pre-start purge, or overheating in operation) (repair-table code)
3PU-5 3 blinks: too many flameouts during operation (repair-table codes 08/29/78; there is no repair code 03) (PU-5 remote blink count)
5Faulty flame indicator (or, on AIR-2D, a faulty temperature sensor): short to casing or open circuit in the sensor wiring (repair-table code)
6Fault 06 (same as 04): control unit integrated temperature sensor failed; replace the control unit (repair-table code)
8PU-5 8 blinks: no communication between panel and control unit (repair code 20). Repair code 08 is flame failure, see 29 (PU-5 remote blink count)
9Faulty glow plug: short circuit, open circuit or faulty control unit (repair-table code)
10Air blower motor does not develop the necessary speed (friction in bearings, impeller touching shroud, faulty motor) (repair-table code)
12Shutdown due to overvoltage: above 30 V (24 V heater) or above 16 V (12 V heater) (repair-table code)
13Heater did not start - two automatic start attempts failed (repair-table code)
17Faulty fuel pump: short or open circuit in the pump wiring (or blown fuse) (repair-table code)
20Heater does not start: no communication between the controller and the control unit (controller receives no data from the control unit) (repair-table code)
27Air blower motor does not rotate (damaged bearing or rotor, foreign objects) (repair-table code)
29Flame failure during operation (insufficient fuel, faulty pump, faulty flame indicator); code 08 refers to 29 (repair-table code)
30Heater does not start: no communication between the controller and the control unit (control unit receives no data from the controller) (repair-table code)
