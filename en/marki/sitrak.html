The reference covers 226 codes from the factory tables of SITRAK — the full list by system is below, stop-now codes first.

SITRAK codes: what to know

SITRAK records codes under J1939: the SPN and the FMI come as a pair. The free tables cover 226 codes. The most common are the exhaust and AdBlue system, intake and boost, and the power supply. Most codes have no standard SPN name, so the component name on the code page is taken from the factory entry. If the FMI is electrical (3 to 6), start with the connector and the circuit, not the component itself.

How to read a code

A code has two halves. SPN is what is actually at fault — the sensor, component, or parameter. FMI is what is wrong with it — value out of range, open circuit, short circuit, invalid data. So “SPN 100” alone is not a diagnosis yet, but “100/1” already tells you oil pressure has dropped below normal.

If there are several codes at once

That is almost always how it goes: one fault drags five or six codes behind it. An empty AdBlue tank first throws a level error, then interrupted dosing, then a NOx excess and a torque derate.
