Detroit Diesel fault codes

The reference covers 1120 codes from the factory tables of Detroit Diesel, grouped by control module (MID).

Detroit Diesel codes: what to know

Detroit Diesel is written like Mack: the MID module number, the PID/SID and the FMI. The reading covers the DDEC engine unit (module 128), with 1120 codes in total. If the parameter is not clear from the code, check it against the same row in the table, not against a general description of the fault.

How to read a code

A code has three parts: MID is which control unit reported it, PID/SID is which parameter or component is at fault, FMI is the type of fault (short circuit, open circuit, value out of range). On the scanner the code usually shows as MID-PID/SID-FMI, e.g. MID128 PID100 FMI4.

Know the code number? Type it into the search — or paste the whole list from the scanner and we will show which fault is the real one.
