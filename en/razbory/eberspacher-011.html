Eberspächer shows 011: the heater is not getting enough voltage

In short. Code 011 is not about the burner or the fuel: the control unit received too little voltage and shut the heater down. Start with the fuses, the power wires, the ground and the positive battery terminal.

The Eberspächer went out and the controller shows AF and 011. This is code 011, low voltage: the voltage at the control unit stayed below normal for more than twenty seconds, so the heater shut down. Check the battery charge and the terminals. Then check the heater fuse and replace it if needed. If that does not help, take it to a workshop.

What the unit actually records

In the Eberspächer factory table, 011 is undervoltage with shutdown. The condition is simple: the voltage at the control unit stayed low for at least 20 seconds in a row. A brief dip does not set the code.

The thresholds differ slightly between manuals:

How the code looks on different controllers

The same fault is shown differently, so you will not see "011" everywhere:

ControllerWhat the driver sees
Old modular timer 1531A three-digit number 011 marked AF (active fault) or F1-F5 (from memory)
EasyStart ProNo number: a red flashing ring on the button and the text "Undervoltage"
EasyStart SelectNo number: an icon meaning "heater off, undervoltage"

What to check without instruments

For code 011 the factory names four checks; do them in this order:

  1. The fuses in the heater circuit.
  2. The power wires to the heater: breaks, corrosion, damaged insulation.
  3. The negative connections (ground): tight and clean.
  4. The positive battery terminal: corrosion and a firm contact.

Everything else is measuring and replacing parts.

When to go to a workshop

  • the code returns after the fuses, wires, ground and terminal have been checked;
  • the voltage at the heater connector has to be measured: per the manual it should equal the battery voltage, and that measurement is a workshop job.

Questions and answers

How is 011 different from 010?

011 means there is too little voltage, 010 too much (above 16 V on a 12 V system and above 32 V on a 24 V system). Both are set if the condition lasts at least 20 seconds.

Why does my controller not show 011?

EasyStart Pro shows a red flashing ring and the word Undervoltage instead of a number, EasyStart Select shows an icon. The old modular timer 1531 shows the three-digit number.

Does it mean the heater is broken?

Not necessarily. The code is about the supply, not the burner or the fuel: the cause is usually a fuse, wiring, ground or the battery terminal.

What voltage should be at the heater connector?

According to the factory manual, the same as at the battery. Measuring it is a workshop task.
