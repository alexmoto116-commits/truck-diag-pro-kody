SPN 1582 — LED Display Data #2

J1939 code SPN 1582. Below — how the fault is worded at the factory by Ford Trucks, and what the second half of the code (FMI) means in the standard.

Ford Trucks

Ford Trucks/Ecotorq writes fault numbers in its own format: the code in the table below is a Ford code (hexadecimal, zero-padded), not a J1939 SPN. It matches the standard only where the signal itself is standard, and usually matches the title of this page by digit alone.

FMI 0DPM Dosing Valve – High Current
FMI 1DPM Dosing Valve Electrical – High Circuit Temperature
FMI 2DPM Dosing Valve Electrical – Open / Short to Power (2.pin)
FMI 3DPM Dosing Valve Electrical – Open / Ground Short Circuit (2.pin)
FMI 4DPM Dosing Valve Electrical – Short Circuit (1.pin)

Can I keep driving

Do not drive. Stop as soon as it’s safe to do so — don’t keep going.

What happens if you keep driving

Time you have: To the nearest safe stop

The code is flagged critical: the manufacturer considers it unsafe to keep driving without checking.

This code alone cannot say what will fail next, so stop at the first safe opportunity and look at it on the spot.

That said, the manufacturer flags this code as critical — if in doubt, it is safer to stop and check on the spot.
