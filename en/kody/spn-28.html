SPN 28 — Accelerator Pedal Position #3

Do not driveTo the nearest safe stop

J1939 code SPN 28. Below — how the fault is worded at the factory by Ford Trucks, Renault Trucks and ZF AS-Tronic, and what the second half of the code (FMI) means in the standard.

Ford TrucksRenault TrucksZF AS-Tronic

Ford Trucks

FMI 0Urea Temperature and Level Sensor Communication Interruption

Renault Trucks

FMI 8Transmission retarder torque signal fault. Repair: Run the diagnostic check of the intarder electronic unit. Check the Astronic unit parameters. Switch the ignition off, switch it on again and repeat the test. If the fault persists, replace the control unit.

ZF AS-Tronic

ZF AS-Tronic uses its own fault numbering: the number in the table below is an internal ZF code, not a J1939 SPN. It matches the title of this page by digit only and means something different.

FMI 8No CAN bus signal: "driveline retarder — actual percent torque".

What FMI means in J1939

SPN 28 FMI 028/0 · 28.0data above normal range (most severe level)
SPN 28 FMI 828/8 · 28.8abnormal frequency or pulse width

Can I keep driving

Do not drive. Stop as soon as it’s safe to do so — don’t keep going.

What happens if you keep driving

Time you have: To the nearest safe stop

The code is flagged critical: the manufacturer considers it unsafe to keep driving without checking.

This code alone cannot say what will fail next, so stop at the first safe opportunity and look at it on the spot.

That said, the manufacturer flags this code as critical — if in doubt, it is safer to stop and check on the spot.
