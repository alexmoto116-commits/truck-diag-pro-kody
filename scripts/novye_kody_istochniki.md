# Источники: разделы /j1587/ и /vag-otopiteli/ (09.11.2026)

Данные: `scripts/j1587_data.py`, `scripts/vagaux_data.py`. Страницы строит `scripts/novye_kody.py`. Закрытые дилерские базы не использовались, `pcode.json` не читался.

## Блок А: J1587/J1708 (27 страниц ru + 27 en + оглавление)

Источники (ключи в `j1587_data.SRC`):
1. SAE J1587, ред. 02.2002 (открытая копия, cdn.hackaday.io): таблица MID, список PID, таблица SID, таблица FMI. Названия PID/SID и смысл FMI брались отсюда.
2. Таблицы кодов Volvo MID 128, 130, 136, 140, 144 (pdfcoffee.com/codigo-de-error-volvo-pdf-free.html): какие PID/SID/FMI есть у блока, названия строк.
3. Volvo TSI, стр. 233: MID 144 SID 231 «SAE J1939 Control Link» (FMI 2 и 12, причины, реакция блока). Использован для SID 231.
4. Volvo VNL, стр. 148 (manualslib): список MID (128 двигатель, 130 коробка, 136 ABS, 140 приборы, 144 Cab Controller).

Каждая страница опирается минимум на 1 и 2 (названия по SAE, набор FMI по Volvo). Страницы SID 231 — ещё на 3 (MID 128, 130, 144) и 4 (MID 144).

Не получено (отмечено на страницах): таблица Mack (class8truckparts дал 403), Volvo MID136 manual (manualmachine, 403). FMI по строкам MID 136 в таблице Volvo (pdfcoffee) нечитаемы, поэтому на страницах MID 136 FMI по строке не названы.

### Расхождения
- MID 144: SAE — круиз-контроль; Volvo — ЭБУ автомобиля (VECU); руководство VNL — «Cab Controller». Отмечено на странице.
- FMI 9: SAE — «неверная частота обновления данных»; Volvo — «ошибка связи». Отмечено.
- FMI 15: у SAE зарезервирован, в таблице Volvo — «Abnormal update rate / Unknown». В оглавлении не используется.
- SID 231: SAE — «SAE J1939 Data Link»; Volvo у MID 128 — «SAE J1939 Control Link»; у MID 136 — «J1939 Not Communicating». Названия приведены как есть.
- Для Mack, Freightliner, International, Detroit, Kenworth, Peterbilt открытых таблиц с FMI не нашли: на страницах указано «сверяйте с руководством вашей марки».
- Форум-повод (forum.truck.ru, тема «mid 130 sid231 FMI 2 / mid 140 sid 231 fmi 11»): ответа по сути нет; тема на страницы не ссылается. MID 140 SID 231 FMI 11 в таблице Volvo не перечислен (там только FMI 2), эту комбинацию в тексте не разбирали.

## Блок Б: отопители VAG, блок 18 Aux. Heat (16 страниц ru + 16 en + оглавление; 3 страницы сняты 10.11.2026)

Источники (ключи в `vagaux_data.SRC`):
- `a4`: Audi A4 (8E), таблица неисправностей отопителя, коды от 01406 (workshop-manuals.com, открытая копия руководства).
- `a2`: Audi A2, таблица неисправностей дополнительного отопителя (workshop-manuals.com).
- `rt01406`, `rt01407`, `rt01794`, `rt02251`, `rt65535`: страницы Ross-Tech wiki (wiki.ross-tech.com/wiki/index.php/<код>). Страниц для 01408-01416, 01443, 01444, 02243 в wiki нет (404 на 09.11.2026).
- `rtf`: форум Ross-Tech, тема 26379 (01410, 01411, 02251 на Webasto).
- `t6a`: t6forum, «Webasto Coolant Heater Lockout - Codes» (0056, 0002, 0057, 0135, 02251).
- `t6b`: t6forum, «VCDS And Carista Fault Codes», стр. 2 (02243, короткие коды блока 18).
- `t6c`: t6forum, «Coding procedure for a used Eberspacher D3 plus» (02243, замена потолочного дисплея, кодировка).

Две независимые опоры на каждый код:
- 01406, 01407: a4 + a2 + Ross-Tech wiki.
- 01408, 01409, 01413, 01414, 01415, 01416, 01443, 01444: a4 + a2 (две заводские таблицы разных моделей).
- 01410, 01411: a4 + a2 + форум Ross-Tech.
- 01412: a2 + Ross-Tech wiki 02251 (цитата TPI 2016660). В таблице A4 (как её прочитал агент) этого кода нет; пометка на странице.
- 01794: a4 + Ross-Tech wiki. 65535: a4 + a2 + Ross-Tech wiki.
- 02251: Ross-Tech wiki + форум Ross-Tech + t6forum.
- 0056/0002/0057 и 0135 (T6): две разные темы t6forum (t6a, t6b). Слабее заводских, помечено.
- 02243: только две темы t6forum (t6b, t6c), другие источники не найдены. Помечено на странице и в оглавлении, формулировки осторожные. Если Алекс считает два форумных источника недостаточными, страницу можно снять в `vagaux_data.PAGES`.

Сняты 10.11.2026 по решению Алекса (источники только темы t6forum, без заводской таблицы и Ross-Tech wiki): 02243 (t6b, t6c), 0056/0002/0057 и 0135 (t6a, t6b). Ссылки t6b и t6c из SRC убраны; t6a остаётся у страницы 02251 (там есть Ross-Tech wiki и форум Ross-Tech).

Отложены (один источник): 01490 (датчик пламени G64), 01491 (свеча Q9) — только таблица A4; 00361 (нагревательный элемент Z35) — только Ross-Tech; 0036, 0040, 0266, 0280/0281, 0373-0376 (короткие коды T6) — только пост в t6forum.

### Расхождения
- 01411: A4 — неправдоподобный сигнал/провода/датчик G18, ремонт проводов и деталей; A2 — причина в блоке управления, ремонт заменой отопителя; форум Ross-Tech — помогла замена G18. Оба варианта изложены.
- 01412/01490/01491: A2 и Ross-Tech называют свечу с датчиком пламени Q8 под кодом 01412; A4 разделяет датчик пламени G64 (01490) и свечу Q9 (01491).
- 02251: Ross-Tech — адаптационные каналы по моделям; t6forum — «Базовые установки» T6 (IDE06654), предохранитель на 10 секунд, Webasto Thermo Test; форум предлагает ещё адаптацию IDE06688 (непроверено, на странице не использовано).
- Подписи Carista к 0056/0002/0057/0135 расходятся с описанием участников форума; на страницах приведена трактовка форума и предупреждение сверять по VCDS.
